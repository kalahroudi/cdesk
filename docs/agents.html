Built for agents

The app bundle includes cdesk-mcp, a stdio Model Context Protocol server. It works without the app being open.

Setup

The server lives at:

Path
/Applications/CDesk.app/Contents/MacOS/cdesk-mcp

Claude Code

Terminal
claude mcp add cdesk -- /Applications/CDesk.app/Contents/MacOS/cdesk-mcp

Claude Desktop, Cursor and others

Add this to the client’s MCP configuration JSON:

JSON
{
  "mcpServers": {
    "cdesk": {
      "command": "/Applications/CDesk.app/Contents/MacOS/cdesk-mcp"
    }
  }
}

Easiest of all: open Settings, then Agents (MCP). CDesk detects Claude Code, Claude Desktop, Cursor, Windsurf, Gemini CLI and Codex CLI on your Mac and shows a Connect button for each. Press it and the button changes to Connected, with Disconnect if you change your mind. Existing settings in each agent's config are kept, and desktop apps need a restart to load the tools.

Tools

All tools take an optional profile (default default).

Safety model

  • Destructive tools refuse to run without an explicit confirmation: colima_recreate and docker_remove_volume need confirm_name to equal the name, and docker_prune needs confirm set to true.
  • docker_exec is non-interactive.
  • Tell your agent to ask you before any destructive call. The prompt below does.

Example prompts

  • “What is running in Colima right now, and how much memory is it using?”
  • “Recommend a Colima size for this Mac and start a profile with it.”
  • “Show the last 100 log lines of my api container.”
  • “Restart the whole web stack.”
  • “Show what is reclaimable, then ask me before pruning anything.”

Agent prompt

One prompt to install CDesk, register the MCP server and start a profile.

Agent prompt

Paste this into an AI coding agent such as Claude Code and it will do the setup for you. It will not delete anything without asking.

Prompt
Install CDesk on this Mac. 1) Check that Homebrew is installed; if colima or docker are missing run `brew install colima docker`. 2) Run `curl -fsSL https://raw.githubusercontent.com/kalahroudi/cdesk/main/scripts/install.sh | bash`. 3) Register its MCP server: `claude mcp add cdesk -- /Applications/CDesk.app/Contents/MacOS/cdesk-mcp`. 4) Call colima_profiles; if there are none, call colima_recommend and start a profile with the recommended cpus/memory_gib/disk_gib via colima_start. 5) Tell me what is running. Never call colima_recreate, docker_remove_volume or docker_prune without asking me first.
